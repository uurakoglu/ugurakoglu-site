Administration

Administering software you don't use yourself: running 15+ engineering applications

Part of my job is to administer the licensing and server side of more than fifteen engineering applications. They range from simulation and analysis tools to CAD, electronics, test and PLM software. I do not use most of them as an engineer does, and that is exactly how the role works.

A very uneven user base

Some tools have one user. For those, I support that person directly whenever a licence problem appears. Others are used across departments: analysis engineers, architects who need drawing tools, specialists who use particular CAD packages. For the widely used ones there is no single user count, since the users sit in many teams.

What administering means in practice

  • First activation. I contact the vendor, install the software on the server and put the licence into service.
  • Installation documents. I write the setup instructions, and the support team installs clients from them.
  • Ongoing support. When a user runs into a licence problem or a problem in the application itself, I help understand it and resolve it.
  • Training requests. A team sometimes wants the vendor to train a few people on a tool. I give the vendor our server details, receive a licence file, install it and activate the licences, so the training can take place.

An administrator is not the power user

It is a common misunderstanding that administering a tool means mastering it. I know roughly what each tool is for, and when a problem lands on my desk I learn the part I need in order to understand it properly. My strong ground is PLM, where I know ENOVIA, CATIA and DELMIA in depth. For everything else, the job is to keep the tool available and the users unblocked.

Why a mechanical engineering background helps

The people I support are engineers who think in the language of their own tools. Having a mechanical engineering degree means I can follow what they describe, ask the right follow-up questions and reach a fix faster than if I only saw a licence server log.
